# Инструкция для помощника Hermes: поставить набор фич хозяину

Ты - помощник Hermes. Хозяин прислал тебе этот архив. Твоя задача - поставить ему фичи
из набора в тебя самого (основной помощник, отдельный профиль НЕ создавать).

Правила:
- Говори по-русски, просто, коротко. Перед каждым шагом - одна строка, что делаешь.
- Ничего не удаляй. Твой характер (SOUL.md), настройки и существующий AGENTS.md скрипты не трогают.
- Пароли, ключи и коды хозяин вводит сам, в своём браузере. Не проси их в чат.

## Шаги

1. Распакуй архив в `~/hermes-kit` (если такой папки нет) и перейди в неё.
   Проверь: `bash tools/install-main.sh --list` - должен показать список фич.

2. Покажи хозяину список фич (таблица "Меню фич" в README.md) простыми словами и спроси,
   что ставить. Предложи по умолчанию: models, limits, attention-ping, brain, money-plan,
   calendar, server-watch, backup, secrets, session-watch, media, blocked-pages, pool, pool-watch.
   Спроси имя хозяина (для AGENTS.md и базы).

3. Если выбран шлюз подписок (pool) - сначала поставь его (5-15 минут, собирается из исходника):

       bash tools/pool-install.sh

   Потом вход в подписки, хозяин рядом:

       bash tools/pool-login.sh claude      # подписка Claude Pro/Max
       bash tools/pool-login.sh chatgpt     # подписка ChatGPT Plus/Pro

   Скрипт ждёт ввода - запускай его в фоне с псевдотерминалом (terminal background=true, pty=true)
   и отвечай через process write/submit. Сначала прочитай подсказки, которые печатает скрипт
   (для ChatGPT хозяину надо заранее включить в настройках chatgpt.com "device code authorization").
   Скрипт выдаст ссылку (и код) - перешли хозяину, он входит в свой аккаунт в браузере.
   Для Claude после входа браузер покажет адрес "localhost..." с ошибкой - это нормально,
   хозяин копирует этот адрес целиком и присылает тебе, ты вставляешь его в скрипт.
   Проверка: `bash tools/pool-install.sh --check` - в списке модели Claude и/или GPT.

4. Поставь выбранные фичи (пример - подставь выбор хозяина):

       bash tools/install-main.sh --name "Имя" --server-keeper --on pool,pool-watch,models,limits,brain,money-plan,calendar,session-watch,media,blocked-pages,secrets,server-watch,attention-ping

   `--server-keeper` нужен для server-watch, backup и pool-watch (ты единственный помощник на сервере).

5. Перезапусти себя, чтобы подхватить навыки и плагины: `hermes gateway restart`
   (если в Docker - хозяину: перезапустить контейнер или приложение).

6. Что осталось сделать руками - по README.md каждой выбранной фичи (`features/<id>/README.md`):
   - calendar: один раз вход в Google Календарь;
   - backup: `bash tools/setup-backup.sh` (приватный репозиторий GitHub);
   - остальное работает само.

7. Скажи хозяину итог: что поставлено, что осталось, как переключать модели
   (`/model strong`, `/model main`, `/model light`).

## Если что-то пошло не так

- Скрипт написал "!!" по фиче - прочитай сообщение выше, исправь причину, повтори шаг 4 (повтор безопасен).
- Шлюз не скачивается - интернет-фильтр сервера не пускает на github.com или go.dev: скажи хозяину,
  какой адрес заблокирован.
- Посмотреть, что стоит: `bash tools/install-main.sh --list`. Выключить фичу:
  `bash tools/features.sh --id main --off <фича>`.
