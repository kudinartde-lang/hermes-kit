# Календарь (calendar)

Человек диктует ("встреча с Петровым в пятницу в три") - помощник проверяет пересечения и заносит в
Google Календарь. Из записи встречи вытаскивает все задачи с датами.

    tools/features.sh --id anna --on calendar

Потом один раз вход в Google (человек рядом, 10 минут): написать помощнику "подключи мой календарь" -
он проведёт по шагам навыка google-workspace (нужен проект в Google Cloud и вход в свой аккаунт;
доступ только к календарю). Пароль человек вводит сам в браузере.
