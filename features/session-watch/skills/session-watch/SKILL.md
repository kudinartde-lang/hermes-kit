# Наблюдение за рабочей сессией, пока человека нет

Человек закрывает ноутбук и просит: "следи за сессией и пиши в Telegram, что происходит и нужен ли мой ответ".

## Как включить
1. Найти сессию: session_search без аргументов (список последних) -> session_id. Если неясно какую - спросить.
2. Скрипт уже есть: `scripts/session_watch.py <session_id> monitor|digest` в папке помощника
   (читает базу переписок только на чтение, закладка - в cache/).
3. Сделать две обёртки в `scripts/` помощника (у задачи расписания нет аргументов):
   `watch_<x>_monitor.sh` -> `exec python3 "$(dirname "$0")/session_watch.py" <id> monitor`
   `watch_<x>_digest.sh`  -> то же с `digest`.
4. cronjob_manage create: schedule `every 5m`, monitor_script = monitor-обёртка (молчит, если нового нет),
   script = digest-обёртка, deliver по умолчанию (туда, откуда попросили).
   Промпт: 1-3 пункта простыми словами, что произошло; если помощник в сессии задал вопрос -
   "НУЖЕН ТВОЙ ОТВЕТ:" и вопрос дословно.
5. "Хватит следить" -> cronjob_manage remove этой задачи.

## Подводные камни
- Сессия без человека не может получить подтверждение опасных команд (удаления и т.п.) - через 5 минут блок.
  Ответ человека передать в сессию: `hermes chat --resume <id> -Q -q "..."` в фоне,
  с просьбой отложить такие действия до его возвращения.
- Сводка про блок подтверждения звучит тревожно - перед ответом человеку проверить сессию, возможно всё уже решилось.
- Время в сводке - по Москве; другой часовой пояс: переменная WATCH_TZ_OFFSET_HOURS в обёртке.
