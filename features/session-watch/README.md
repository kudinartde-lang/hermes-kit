# Наблюдение за сессией (session-watch)

Человек уходит и говорит помощнику "следи за этой сессией". Каждые 5 минут в Telegram: что сделал
помощник, и если он задал вопрос - "НУЖЕН ТВОЙ ОТВЕТ" с вопросом. Ответ можно дать прямо в Telegram.
"Хватит следить" - выключает.

    tools/features.sh --id anna --on session-watch
