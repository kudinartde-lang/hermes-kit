# Расшифровка аудио и видео (media)

Голосовые, записи встреч, видео и YouTube - в текст на самом сервере (faster-whisper), потом выжимка,
задачи, перевод. YouTube часто блокирует серверы - тогда помощник попросит файл.

    tools/features.sh --id anna --on media

Ставит отдельное окружение `~/.hermes/.venv-media` (1-3 минуты, ~300 МБ). Для видео нужен ffmpeg:
`sudo apt-get install -y ffmpeg`. Первая расшифровка скачает модель (~500 МБ).
