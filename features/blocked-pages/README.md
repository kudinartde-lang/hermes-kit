# Обход закрытых страниц (blocked-pages)

Страница отдаёт 403, "проверку на робота" или платный доступ - помощник ищет её копию: веб-архив,
archive.today, другой вход на тот же сайт, в конце - настоящий браузер. Всегда пишет, откуда копия и
какой она даты.

    tools/features.sh --id anna --on blocked-pages

Навык идёт с самим Hermes (blocked-page-recovery), фича его включает.
