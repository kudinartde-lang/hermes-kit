# Сторож шлюза (pool-watch) - только хранителю сервера

Нужна фича pool. Все задачи без ИИ (лимит подписок не тратят), пустой вывод = тишина.

| Задача | Когда (время сервера) | Что делает |
|---|---|---|
| pool-watchdog | каждые 2 минуты | шлюз упал - поднимает; не поднялся - тревога |
| pool-morning | 9:00 | лимиты и время сброса по каждому аккаунту |
| pool-alerts | 8:55 | только проблемы: все в лимите, вход протух, окно больше 90% |
| pool-backup | 3:40 | копия входов в подписки на сервере (3 последние) |
| pool-update-check | пн 10:10 | в наборе одобрена новая версия шлюза -> `tools/pool-update.sh` |
| pool-model-watch | пн 10:20 | в шлюзе появились/исчезли модели |

    tools/features.sh --id anna --on pool-watch

Скрипты - в `<профиль>/scripts/pool/`, пути - в `pool/env.sh` (пишет установщик).
Время в расписании - по часам сервера (обычно UTC: 9:00 UTC = 12:00 МСК). Поменять:
`hermes -p anna cron edit <id> --schedule "0 6 * * *"`.
