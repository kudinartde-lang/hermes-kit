# codex-limits (копия в установочном наборе)

Чип в приложении Hermes рядом с выбором модели: сколько лимита подписки ChatGPT осталось
(окно 5 часов и неделя) и когда сброс. Только чтение, ничего не меняет.

- Ставится вместе с набором (plugins/codex-limits), отдельно устанавливать не нужно.
- Данные берутся у самого Hermes на сервере (вход hermes auth add openai-codex).
  Если на сервере есть шлюз подписок CLIProxyAPI - покажет и его аккаунты; нет - блок шлюза скрыт.
- В терминале то же самое: `hermes usage`.
- Первый раз блоку "аккаунты Hermes" нужен один перезапуск: `hermes gateway restart`.

Безопасность: токены не покидают сервер, в приложение уходят только тариф, проценты и время сброса.
Скрипт не обновляет токены и ничего не пишет на диск.

Это проверенная копия плагина с открытой лицензией MIT (автор и лицензия - в LICENSE).
Изменения для набора: убраны ссылки на внешние репозитории и кнопка самообновления из интернета,
скрыт блок шлюза, если шлюза нет. Обновляется только вместе с набором.
