# Лимиты в процентах (limits)

Плагин codex-limits: рядом с выбором модели в приложении - сколько лимита осталось (окно 5 часов),
по каждому аккаунту GPT и Claude. Только читает, ничего не меняет.
Своя исправленная копия: проценты Claude считаются верно, чип показывает 5-часовое окно.

    tools/features.sh --id anna --on limits

## Значок в приложении - если помощник на сервере, а приложение на ноутбуке

Приложение Hermes берёт значки только со своего компьютера. Установка на сервере до ноутбука не
дотягивается, поэтому без этого шага значка не будет (хотя помощник на сервере всё знает).
Переключатель в Capabilities -> Plugins и перезапуск сами по себе значок НЕ возвращают.

Самый простой путь - всю фичу целиком (и сервер, и значок) ставит само приложение, архив не нужен:

1. В приложении Hermes: Capabilities -> Plugins -> кнопка **Install from Git**.
2. Вставить ссылку, нажать **Review repository**, потом **Install** (галочки оставить как есть):

       https://github.com/kudinartde-lang/hermes-kit/tree/main/features/limits/plugins/codex-limits

3. Если значок не появился - перезапустить приложение.

Нужен git на ноутбуке. На Mac без него система сама предложит поставить "инструменты разработчика" -
согласиться (Установить), подождать, повторить Install.
