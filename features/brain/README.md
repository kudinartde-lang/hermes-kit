# Второй мозг (brain)

- Общая база компании `~/.hermes/company/brain/` (создаёт add-person.sh из шаблона templates/brain-company).
- AGENTS.md человека - "как со мной работать" (templates/person/AGENTS.md).
- Навыки: second-brain (как вести базу), team-brain (что в общую базу, что в личное).
- Проверки базы:
  - second-brain-weekly - вс 20:00: что человек говорил за неделю, но не попало в базу; отвечает номерами;
  - second-brain-monthly - 1-го числа 10:00: устаревшее, битые ссылки, дубли, вопросы "это ещё так?".
