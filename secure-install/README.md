# Гермес на твоём сервере

Здесь готовая схема защищённой установки Hermes Agent. Она перенесена с рабочего сервера и проверена на нём 25.09.2026.

Ставит всё Claude Code в твоём VS Code. Он идёт по шагам из `CLAUDE.md` и перед каждым этапом спрашивает тебя. Твой VPN он не трогает.

## Что подготовить

1. **Hostinger.** Нужен вход в hPanel. Включи там двухфакторную защиту (2FA).
2. **Доступ к серверу.** Нужны его IP и пароль root (или уже добавленный SSH-ключ).
3. **Ключ к модели ИИ.** Провайдер выбираешь сама.
4. **Telegram.**
   - Создай бота у @BotFather и сохрани токен.
   - Узнай свой ID у @userinfobot.
5. **Bitwarden.** Туда сохранишь пароль от веб-интерфейса.
6. **Claude Code в VS Code.** Нужно расширение Claude Code и вход в свой аккаунт Claude.

## Как запустить

1. Открой эту папку в VS Code: File → Open Folder.
2. Открой Claude Code и напиши: **«Начни установку по CLAUDE.md с фазы 0»**.
3. **Ключи, токены и пароли в чат не вставляй.** Когда они понадобятся, Claude попросит ввести их самой в терминале.

На всё уходит примерно час.

## Что получится

- **Гермес изолирован.** Он работает в изолированном контейнере без прямого выхода в интернет. Наружу он ходит только через фильтр: только HTTPS, без доступа к внутренним сетям и без сервисов, через которые обычно сливают данные.
- **Вход на сервер только по ключу.** Вход по паролю и вход под root закрыты. Включены фаервол, автообновления и защита от подбора (fail2ban).
- **Бот отвечает только тебе.**
- **Веб-интерфейс закрыт для интернета.** Если VPN устроен как на рабочем сервере, веб открывается только через VPN. Если иначе, одной командой через SSH-туннель. Вход держится 30 дней, пароль каждый раз вводить не нужно.
- **Проверка в любой момент.** `scripts/verify.sh` проверяет всю защиту за минуту.

## Что в папке

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | пошаговая инструкция для Claude Code |
| `server/docker-compose.yml` | Гермес и фильтр исходящего трафика |
| `server/egress/squid.conf` | что агенту можно открывать в интернете |
| `server/sshd/00-hardening.conf` | вход на сервер только по ключу |
| `server/env.example` | что означает каждая настройка |
| `server/cron/hermes-squid-log-rotate.sh` | ежедневная чистка журнала фильтра |
| `scripts/discover.sh` | разведка сервера, ничего не меняет |
| `scripts/create-user.sh`, `firewall.sh`, `updates-fail2ban.sh`, `hermes-prepare.sh` | шаги установки |
| `scripts/verify.sh` | итоговая проверка, ничего не меняет |
