# Шаг 1. Сервер компании (делает установщик, ~40 минут)

Один сервер на компанию. На нём живут все помощники сотрудников и общая база.
Сервер оплачивает компания своей картой. Аккаунт у хостинга заводится на компанию.

## 1.1 Какой сервер взять

- Linux, Ubuntu 24.04 (или новее), 2 ядра, 4 ГБ памяти, диск от 40 ГБ. На 2-3 человек хватит.
  Больше 5 человек или голосовые расшифровываются медленно - 8 ГБ.
- Сервер ЗА РУБЕЖОМ (например, Европа). Подписка ChatGPT с российских адресов не работает.
- Подводный камень (152-ФЗ): персональные данные клиентов компании (ФИО + телефон, диагнозы,
  паспорта) на зарубежный сервер НЕ класть. Помощники настроены писать о клиентах обезличенно -
  предупредите об этом владельца отдельно, особенно медицину.
- Хостер выдаёт: адрес сервера (IP), логин root и пароль. Пароль сразу в менеджер паролей компании,
  не в чат и не в заметки.

## 1.2 Отдельный пользователь для Hermes

Зайти на сервер (Mac - Терминал, Windows - PowerShell):

    ssh root@<IP-сервера>

Создать пользователя hermes и разрешить ему работать в фоне:

    adduser --disabled-password --gecos "" hermes
    loginctl enable-linger hermes
    apt update && apt install -y git python3 curl

Ключ установщика, чтобы входить без пароля (со своего компьютера):

    ssh-copy-id hermes@<IP-сервера>

(если ssh-copy-id нет - скопировать свой ~/.ssh/id_ed25519.pub в /home/hermes/.ssh/authorized_keys)

## 1.3 Поставить Hermes

Под пользователем hermes:

    ssh hermes@<IP-сервера>
    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
    source ~/.bashrc
    hermes doctor

hermes doctor не должен показывать красных ошибок.

## 1.4 Скачать установочный набор

    git clone <адрес-набора> ~/hermes-kit

Набор лежит в приватном репозитории того, кто устанавливает. Для скачивания на сервер компании -
отдельный deploy key только на чтение, НЕ ваш личный ключ GitHub.

Часовой пояс в наборе - Москва. Другой город - после установки людей:
`hermes -p <id> config set timezone Asia/Yekaterinburg` (для каждого).

## 1.5 Шлюз (Telegram и расписание)

Один шлюз обслуживает всех помощников сервера. Ставится один раз, после добавления первого человека:

    hermes gateway install
    hermes gateway start
    hermes gateway list

В списке должны быть все помощники. Без работающего шлюза не работают ни Telegram, ни расписание
(утренние планы, проверки базы, сторож сервера).
