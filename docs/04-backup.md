# Шаг 4. Ночной бэкап (~15 минут, один раз на сервер)

Каждую ночь в 3:00 все помощники и общая база копируются в приватный репозиторий GitHub компании.
Если сервер сломается - всё восстанавливается из копии.

Что попадает в копию: общая база, файлы "как со мной работать", память помощников, навыки, настройки.
Что НЕ попадает: ключи и пароли (.env, auth.json), переписки (там могут быть данные клиентов), кэши.
Скрипт сам отменяет копию, если в файл случайно попал живой ключ из .env.

## 4.1 Репозиторий (делает владелец компании)

1. Аккаунт GitHub компании (не установщика!): https://github.com/signup
2. New repository -> имя, например company-backup -> обязательно Private -> Create.
3. Скопировать адрес вида git@github.com:аккаунт/company-backup.git (кнопка Code -> SSH).

## 4.2 На сервере

    cd ~/hermes-kit
    tools/setup-backup.sh --repo git@github.com:аккаунт/company-backup.git --keeper anna

--keeper - тот, кому при добавлении ставили --server-keeper. Скрипт ничего не удаляет и
не отправляет - только готовит папку и печатает открытую часть ключа.

## 4.3 Ключ на GitHub (владелец)

Репозиторий -> Settings -> Deploy keys -> Add deploy key:
- Title: Hermes backup
- Key: строка ssh-ed25519 ..., которую напечатал скрипт
- Allow write access - ВКЛЮЧИТЬ
- Add key

## 4.4 Первая копия и включение

Команды из конца вывода скрипта:

    python3 ~/.hermes/profiles/anna/scripts/git-backup.py

Должно быть "push прошёл". Первая копия - проверить на GitHub, что там нет .env и auth.json.
Потом включить ночной запуск:

    ~/hermes-kit/tools/features.sh --id anna --on backup

## 4.5 Подводные камни

- Большие файлы (больше 90 МБ) в копию не попадают - GitHub их не принимает, скрипт пишет об этом в лог.
- Лог копий: ~/.hermes/logs/git-backup.log
- Переписки всё же нужны в копии - BACKUP_DB_DUMPS=1 (только если владелец понимает, что в копию
  уйдут и данные клиентов из чатов).
- Восстановление: поставить Hermes на новый сервер (docs/01-server.md), затем
  `git clone <репозиторий> ~/.hermes`, заново вход в ChatGPT и токены ботов (их в копии нет, это правильно).
