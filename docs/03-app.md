# Шаг 3. Приложение Hermes на компьютере человека (~15 минут)

Приложение - это окно чата на компьютере. Сам помощник и его память живут на сервере компании:
приложение подключается к серверу по SSH (защищённое соединение по ключу, без паролей).
Выключенный ноутбук ничему не мешает - Telegram и расписание работают с сервера.

## 3.1 Скачать и поставить

1. Открыть https://hermes-agent.nousresearch.com/desktop
2. Windows - скачать установщик для Windows, запустить, "Далее" до конца.
   Если Windows пишет "Система защитила ваш компьютер" - "Подробнее" -> "Выполнить в любом случае".
   Mac - скачать версию для macOS (Apple Silicon), перетащить Hermes в "Программы".
   При первом запуске: правый клик по Hermes -> "Открыть" -> "Открыть".
   Mac на процессоре Intel (до 2020 года) приложение может не поддерживать - тогда только Telegram.
3. При первом запуске приложение предложит настроить провайдера - нажать
   "Choose provider later" (настраивать на ноутбуке ничего не нужно, всё на сервере).
4. Язык интерфейса: Settings -> Appearance -> язык - Русский.

## 3.2 Ключ SSH на компьютере человека

Windows: Пуск -> набрать PowerShell -> открыть. Mac: Программы -> Утилиты -> Терминал.
Ввести (одинаково на обоих):

    ssh-keygen -t ed25519

На все вопросы - просто Enter (три раза). Потом показать открытую часть ключа:

Windows:

    type $env:USERPROFILE\.ssh\id_ed25519.pub

Mac:

    cat ~/.ssh/id_ed25519.pub

Строку "ssh-ed25519 ..." передать установщику (её можно показывать, это не секрет).
Установщик добавляет её на сервер одной строкой в /home/hermes/.ssh/authorized_keys.

Проверка с компьютера человека:

    ssh hermes@<IP-сервера> hermes --version

Первый раз спросит "Are you sure you want to continue connecting" - ввести yes.
Должна появиться версия Hermes.

## 3.3 Подключить приложение к серверу

1. Settings -> Gateways -> Registered gateways -> Add.
2. Kind: SSH.
3. Name: название компании, например "Компания".
4. SSH host: hermes@<IP-сервера>:22
5. Hermes path: оставить пустым. Если Test напишет "Hermes is not installed on the remote host" -
   вписать /home/hermes/.local/bin/hermes
6. Save connection -> Test -> должно быть "Reachable".
7. В списке шлюзов выбрать этот сервер, внизу слева - профиль человека (например anna).
   Остальные профили можно скрыть: правый клик -> Hide.

Подводный камень: на одном ключе SSH человек технически может открыть и профиль коллеги.
Для партнёров "без секретов" это нормально. Если нужно жёстко разделить - это отдельная
настройка (отдельный пользователь Linux на человека), обсудить с установщиком.

## 3.4 Удобные настройки

- Settings -> Appearance -> Interface mode -> Simple (проще для не-технаря).
- Выбор модели - в строке ввода слева от микрофона. Обычно ничего менять не надо.
- Чип с процентом рядом с моделью - сколько лимита подписки осталось.
- Звуковой сигнал - когда помощник ждёт ответа или подтверждения.
- Микрофон - диктовка голосом.

## 3.5 Проверка

Написать в приложении: "Что ты обо мне знаешь?" Помощник должен ответить то же, что знает
в Telegram - это один и тот же помощник.
