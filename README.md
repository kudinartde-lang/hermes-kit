# Установочный набор помощника Hermes

## Скачать фичу по ссылке

Каждая фича - один архив. Скачал, отправил своему помощнику Hermes и написал:
**"Распакуй архив и выполни в папке: bash install.sh ИМЯ. Потом расскажи, что поставилось."** (ИМЯ - второй столбец)

Личный ИИ-помощник для владельца компании и сотрудников: у каждого свой помощник
(своя память, свой Telegram-бот), у компании одна общая база знаний, которую видят все.

Набор устроен как **меню**: основа ставится всегда, остальные фичи каждый человек выбирает сам -
что хочет, а что нет. Выбор можно поменять в любой момент.

В наборе нет ничьих ключей и личных данных - только шаблоны. У каждой компании свои
аккаунты, ключи и карта.


## Значки в приложении (Лимиты, Сигнал "жду ответа") - без архива, прямо из приложения

Эти две фичи видны в самом приложении Hermes, поэтому их удобнее ставить оттуда - одной кнопкой
(ставится всё сразу: и часть на сервере, и значок на ноутбуке):

1. В приложении Hermes: Capabilities -> Plugins -> кнопка **Install from Git**.
2. Вставить ссылку, нажать **Review repository**, потом **Install** (галочки оставить как есть).
3. Если значок не появился - перезапустить приложение.

| Фича | Ссылка для Install from Git |
|---|---|
| Лимиты в процентах | https://github.com/kudinartde-lang/hermes-kit/tree/main/features/limits/plugins/codex-limits |
| Сигнал "жду ответа" | https://github.com/kudinartde-lang/hermes-kit/tree/main/features/attention-ping/plugins/attention-ping |

## Шаг 0. Основа - защищённый сервер с Hermes (всегда)

`secure-install/` - Hermes в Docker без прямого выхода в интернет (только через фильтр),
вход на сервер только по ключу, фаервол, автообновления, защита от подбора пароля, веб только
из VPN или через SSH-туннель. Ставит Claude Code в VS Code по шагам из `secure-install/CLAUDE.md`,
перед каждым этапом спрашивает. Начать: `secure-install/README.md`.

Основа помощника (ставится каждому): характер (SOUL.md - знакомится, говорит по-русски просто,
ничего не отправляет наружу без команды), настройки (модели, Москва, голосовые на сервере).

## Одна фича - один архив (самый простой путь)

У каждой фичи свой архив `hermes-<фича>.zip`. Человеку ничего настраивать не нужно:
1. Отправить архив своему помощнику Hermes (в приложении или в Telegram).
2. Написать: "Распакуй архив и выполни в папке: bash install.sh <фича>. Потом расскажи, что поставилось."

Помощник ставит фичу в себя (SOUL.md, модель и настройки не трогает), нужные для неё фичи ставит сам
(план дня тянет второй мозг, сторож шлюза - шлюз). Сводки идут в Telegram, если он подключён, иначе в приложение.
Собрать архивы: `bash tools/build-feature-zips.sh zips`.
Шлюз подписок (`pool`) исключение: после установки человек сам входит в свои подписки (`bash tools/pool-login.sh`).

У каждой фичи своя папка `features/<id>/` и `README.md`: что делает и что сделать руками.
Каталог - `features/catalog.tsv`.

## Как выбирать

    tools/features.sh --id anna                      # меню: по каждой фиче "ставить? да/нет"
    tools/features.sh --id anna --list               # что есть и что уже стоит
    tools/features.sh --id anna --on calendar,media  # добавить
    tools/features.sh --id anna --off money-plan     # выключить (ничего не удаляет: пауза)

При добавлении человека меню открывается само (или сразу `--features a,b` / `--all-default`).

## Установка по шагам

1. Основа: `secure-install/README.md` (или docs/01-server.md для сервера без Docker).
2. Шлюз подписок, если нужен (один раз на сервер): `features/pool/README.md`.
3. docs/02-person.md - добавить человека и выбрать ему фичи (на каждого).
4. docs/03-app.md - приложение на компьютере (Windows и Mac).
5. docs/04-backup.md - ночной бэкап (один раз).
6. docs/05-update.md - как обновлять набор.

Коротко:

    git clone <адрес-набора> ~/hermes-kit && cd ~/hermes-kit
    tools/pool-install.sh && tools/pool-login.sh chatgpt && tools/pool-login.sh claude   # если нужен шлюз
    tools/add-person.sh --id anna --name "Анна" --company "Компания" --role "владелец" --server-keeper
    tools/add-person.sh --id petr --name "Пётр" --company "Компания" --role "финансы"
    hermes -p anna gateway setup              # его Telegram-бот
    hermes gateway install && hermes gateway start

Без шлюза подписок - вход в ChatGPT прямо в помощника: `hermes -p anna auth add openai-codex`,
на Claude: `tools/use-claude.sh --id anna`.

## Скрипты установщика

- tools/add-person.sh - добавить человека (помощник, общая база, меню фич).
- tools/features.sh - меню фич: поставить, выключить, посмотреть.
- tools/install-main.sh - поставить фичи в основного помощника (без отдельных профилей). Инструкция для самого помощника - УСТАНОВКА-В-МОЕГО-ГЕРМЕСА.md.
- tools/pool-install.sh, pool-login.sh, pool-update.sh - шлюз подписок: установка, вход, обновление.
- tools/use-claude.sh - помощник на подписке Claude без шлюза.
- tools/setup-backup.sh - подготовить ночной бэкап сервера.
- tools/update-all.sh - обновить основу и выбранные фичи у всех помощников.
- tools/enable-jobs.sh - включить заново расписание выбранных фич.
- tools/check-clean.sh - проверка набора перед выпуском: ключи, почты, пути, личные слова.

## Правила набора

- Никаких ключей, паролей, имён и сумм - ни установщика, ни клиентов. Перед каждым выпуском -
  проверка: `tools/check-clean.sh`.
- Чужой код - только проверенной копией внутри набора, со ссылкой на лицензию
  (codex-limits и обвязка шлюза hermes-codex-pool - MIT; сам шлюз CLIProxyAPI собирается из исходника авторов
  одобренной версии).
- Скрипты ничего не удаляют и не перезаписывают; повторный запуск безопасен.
